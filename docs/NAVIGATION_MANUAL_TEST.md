# 案内機能 実機最終確認

自動テストではGPS、端末TTS、振動、Google Mapsの実表示までは再現できないため、AndroidまたはiPhoneで以下を1回確認する。

## 事前準備

1. Expressバックエンドを端末から到達できるHTTPS URLで起動する。
2. Androidは`android/local.properties`へ制限済みの`MAPS_API_KEY`を設定する。iOSはAppDelegateへiOS用キーを設定する。
3. `--dart-define=API_BASE_URL=https://...`を指定してビルドする。
4. 位置情報を「アプリの使用中のみ許可」、端末のメディア音量を聞こえる大きさにする。

## 安全な確認手順

- 実走行は交通量のない安全な場所で行い、操作するときは必ず停車する。
- 片道で近い目的地を選び、案内開始直後に現在地マーカー、次の操作、残距離・残時間が表示されることを確認する。
- 曲がり角の約300m以内と約70m以内で、同じ案内が連続再生されず、日本語音声と振動が発生することを確認する。
- 音声ボタンをオフにし、読み上げは止まるが曲がり角の振動は残ることを確認する。
- 安全な場所でルートから70m以上外れ、3回の位置更新後に「ルートを再検索」と表示され、新しい線へ変わることを確認する。
- 目的地から約60m以内で到着表示になることを確認する。
- 往復では到着後に滞在画面へ変わり、今すぐ折り返す操作と設定時間経過の両方で復路が表示されることを確認する。
- 復路の案内先が、候補検索時ではなく実際に「案内開始」を押した地点になっていることを確認する。
- 案内中は画面が自動消灯せず、滞在・案内終了・到着後には通常どおり消灯できることを確認する。

## 異常系

- 案内開始前に機内モードへ切り替え、通信エラーが表示され画面がクラッシュしないこと。
- 位置情報をオフにし、設定確認のメッセージが出ること。
- 案内中に通信を切ってルートを外れ、現在のルート線を残したまま再検索失敗が表示されること。
